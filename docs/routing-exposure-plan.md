## 1. 要約

- 今の自動車のリスクは「その道で起きた事故の件数」で測っている。件数は交通量に比例して増えるので、交通量の多い幹線道路ほど危険に見え、経路が生活道路へ流れる。
- 計画書5.5節では、これを生活道路の係数 c で抑えることにしていた。しかし、c の値を決める外部の根拠がなかった。
- 本計画では c をやめる。代わりに、自専道・幹線・生活の3区分それぞれに係数を掛ける。係数は、**国交省の死傷事故率（件/億台キロ）を区分の平均として再現する値**とする。
- 係数の主案は、地図への割り当てを通さずに、公的な統計だけから計算する。使うのは、警察の事故データの路線コードによる区分別の事故件数、国交省の道路延長、国交省の事故率の3つである。幹線を1として、**生活15.0、自専道0.27**。
- 比較のため、国交省の数字だけから出した値（生活13.5）と、OSMへの割り当てから出した値（生活18.8）でも経路を作る。
- 係数は辺と交差点クラスタの両方に掛ける。交差点に掛けない場合とも比べる。徒歩・自転車は今のまま変えない。
- 評価では、今のY（事故件数）を主にし、同じ係数を掛けた「曝露を補正した参考値」を並べる。参考値は、補正の仮定が評価の側にも入るので、独立した検証にはならない。

## 2. 背景

### 2.1 件数でリスクを測ることの問題

計画書5.1節のモデルは、交通量を説明変数に持たない安全性能関数（SPF）に、経験ベイズを組み合わせたものである。辺のリスクは「その辺で起きると期待される事故件数」になる。

道路安全の分野では、事故件数は交通量に強く依存するとされ、利用者1人あたりの危険（曝露量あたりの事故率）とは区別して扱う [7][8]。経路探索で示したいのは「自分の車1台がその道を通ったときの危険」で、これは事故件数を交通量で割った事故率にあたる。件数のままでは、交通量の多さが危険の大きさに見える。

M5の実測で、この偏りが大きいことが分かった（`data/work/M5/csweep/`、自動車400 OD、遠回り上限10分、2023年で評価）。

| | 最短時間経路（p0） | 事故考慮経路（c=1） |
|---|---|---|
| 生活道路（classes 10〜13）を走る距離の割合 | 4.9% | 38.6%（ODごとの増加の平均 x=+44.1ポイント） |
| trunk の割合 | 23.6% | 2.6% |
| primary の割合 | 25.4% | 4.4% |
| unclassified の割合 | 2.7% | 20% |
| residential の割合 | 1.7% | 16% |

### 2.2 これまでの対処（係数 c）と、その限界

計画書5.5節の c は、group 5〜8（unclassified・residential・living_street・service）の辺のリスクに掛ける係数である。掃引の結果は次のとおり。

| c | x（ポイント） | 生活道路の割合 | y（Y1〜Y3の平均削減率） |
|---:|---:|---:|---:|
| 1 | +44.1 | 38.6% | 57.8% [55.3, 60.2] |
| 6 | +41.2 | 36.2% | 58.1% |
| 10 | +38.4 | — | 58.0% |
| 20 | +32.6 | — | 56.8% |
| 40 | +21.8 | 21.6% | 53.2% |
| 100 | +8.4 | 11.7% | 46.4% [44.1, 48.6] |

問題は3つある。

1. **値の根拠がない。** 計画書5.5節の「折れ目で決める」規則は、グリッドの範囲で答えが変わった（1〜6の範囲では c=2、1〜100の範囲では c=20）。
2. **c は交差点クラスタに掛からない。** 生活道路側の事故の半分強は交差点クラスタにある（4.3節）。
3. **tertiary が対象外になっている。** 警察の路線コードと照らすと、OSMの tertiary の事故の94〜97%は市町村道である（4.3節）。

### 2.3 交通量のデータの現状

- OSMの `lanes`・`width` は、unclassified・residential・service の延長の98%で不明である（M5で実測）。
- 道路交通センサスの観測は国県道が中心で、OSMとの対応付けには大きな作業が要る（計画書5.7節）。
- 市町村道の走行台キロは、国の統計でも直接は測っていない。全体の走行台キロから幹線と高速の分を引いた残りとして推計している [2]。

辺ごとの交通量は得られない。得られるのは、国交省が公表している**区分ごとの平均の事故率**である。本計画はこれを使う。

## 3. 国交省の一次資料から分かること

資料は11章の [1]〜[6]。[1] と [2] は全ページを読んだ。[3]〜[6] は、生活道路の定義・事故率・走行台キロが載ったページを読んだ。

### 3.1 「生活道路」には定義が2つある

| | 管理者による区分 | 車道幅員による区分 |
|---|---|---|
| 幹線道路 | 一般国道・主要地方道・一般都道府県道（自専道との重複は除く）[2] | 車道幅員5.5m以上 [3][4] |
| 生活道路 | 上記と自専道以外の道路（市町村道、農道・私道など）[1][2]。センサス対象区間の政令市管理の一般市道も生活道路側 [5] | 車道幅員5.5m未満 [3][4] |
| 使われ方 | 道路延長、走行台キロ、**死傷事故率** | 交通事故統計年報による事故件数の推移 |
| 延長 | 幹線18.1万km（15%）、生活101.6万km（85%）（H21）[1] | 記載なし |
| 死傷事故の割合 | 幹線36.2万件、生活36.3万件で約半々（H21）[1] | 生活道路は約22〜27%：H16 72万件対21万件、R2 22万件対8万件 [3]、R5 22万件対7万件 [4] |

**事故率が公表されているのは管理者区分だけ**である。2つの区分の重なり方は国交省の資料にはないので、警察の事故データ（自動車が関与する事故、2019〜2022年）で直接数えた。

| | 割合 |
|---|---:|
| 市町村道の単路の事故のうち、車道幅員5.5m未満 | 27.4% |
| 国県道の単路の事故のうち、車道幅員5.5m未満 | 9.2% |
| 車道幅員5.5m未満の単路の事故のうち、市町村道 | 61.6% |
| 車道幅員5.5m未満の単路の事故のうち、国県道 | 34.8% |

市町村道の単路の事故の約7割は、幅5.5m以上の道で起きている。2つの定義は重なりが小さく、別の物差しとして扱う必要がある。

### 3.2 死傷事故率

| 年 | 自専道 | 幹線 | 生活 | 生活÷幹線 | 出典 |
|---|---:|---:|---:|---:|---|
| H20 | 10 | 84 | 203 | 2.42 | [1] スライド4・8 |
| H20（歩行者・自転車の事故） | — | 17.4 | 81.1 | 4.7 | [1] スライド4 |
| H27 | 9 | 62 | 142 | 2.29 | [2] スライド2 |

- 単位は件/億台キロで、死傷事故件数を走行台キロで割った値である [6]。
- **生活道路の走行台キロは推計値である。** 自動車輸送統計の総走行台キロから、道路交通センサスの高速道路と幹線道路の走行台キロを引いた残り [2]。総走行台キロの誤差がすべて生活道路にかかるので、生活道路の事故率は他の区分より不確かである。
- 歩行者・自転車の4.7倍も「自動車の億台キロあたり」の比で、歩行者や自転車の通行量あたりの危険ではない。

### 3.3 延長あたりの事故件数と、そこから出る交通量の比

H20の延長あたりの死傷事故は、幹線2.06件/km、生活0.37件/kmで、比は5.6 [1]（スライド8）。事故率は「延長あたりの件数 ÷ 延長あたりの交通量」なので、2つの比から交通量の比が出る。

```text
交通量の比（幹線÷生活）= 事故率の比（生活÷幹線）× 延長あたり件数の比（幹線÷生活）
                       = (203/84) × (2.06/0.37) = 2.42 × 5.57 ≈ 13.5
1日あたりの台数に直すと：幹線 2.06/84 億台キロ/km/年 ≈ 6,700台/日、生活 0.37/203 ≈ 500台/日
```

この13.5は資料に直接は書かれていないが、資料の数字だけから出せる。

### 3.4 事故の型：生活道路の事故は交差点に多い

H21の事故類型で最も多いのは、幹線では追突（44.4%）、生活道路では出会い頭（40.2%）である [1]（スライド9）。

### 3.5 幹線道路の事故は一部の区間に集まる

- 国県道の約71万区間のうち、22%の区間に死傷事故の71%が集まり、50%の区間では事故が0件（H15〜18）[1]（スライド7）。
- 12%の区間に59%（H22〜25、[2] スライド5）。9%の区間に56%（H17、[5]）。

事故率の2.3〜2.4倍は区分の平均の比で、区間ごとの差はこれよりずっと大きい。

### 3.6 事故の起きていない道の危険について、国交省のやり方

- 「生活道路対策エリア」（H28〜）と事故危険箇所のB基準では、ETC2.0の急ブレーキ・30km/h超過の割合・抜け道としての利用の記録で、潜在的な危険箇所を選ぶ [2]（スライド5・10）[4]（スライド7）。対策する箇所を選ぶための使い方で、km単位の事故率は推定していない。
- 速度と被害：生活道路では、30km/hを超えると死亡事故の割合が1.70%で、30km/h以下（0.34%）の約5倍 [3]。歩行者の致死率は、時速0〜20kmの0.6%から、50〜60kmでは17.0%に上がる [4]。

### 3.7 二次資料の数字の扱い

「幹線道路は生活道路の3倍安全」とする二次資料（民間の実証実験のチラシなど）があるが、一次資料の事故率の比は2.3〜2.4倍である。本計画は一次資料の数字だけを使う。

### 4.1 区分とOSMのgroupの対応

### 4.2 延長：上下線を1本に数えると、幹線は国交省と一致する

OSMは中央分離帯のある道路を上下線の2本で描く。上下線の双子（形式書10章 `TWIN`）を持つ辺の延長を半分にして、中心線の延長に直した（`exposure_lens.py`）。

| | OSMの延長（上下線を別に数える） | OSMの中心線の延長 | 国交省の延長 |
|---|---:|---:|---:|
| 自専道 | 3.3万km | 2.1万km（ランプを含む） | 1.0万km（H22）、1.3万km（H30）[2] |
| 幹線 | 19.5万km | **18.12万km** | **18.12万km**（H21）[1] |
| 生活 | 116.7万km | 116.6万km（serviceを除くと104.1万km） | 101.6万km（H21）[1] |

幹線の中心線の延長は、国交省の値と0.1%以内で一致した。生活は、service（私道・駐車場の通路など）を除くと2.5%の差である。

### 4.3 事故：警察の路線コードとOSMの割り当ての照合

自動車が関与する2019〜2022年の事故について、1件ごとに警察の路線コードの区分と、割り当てたOSMの区分を突き合わせた（`exposure_xtab.py`。割り当ての重みで数え、双子への写し `MIRROR` は除く）。

| 路線コード＼OSM | OSM自専道 | OSM幹線 | OSM生活 | 行の計 |
|---|---:|---:|---:|---:|
| 自専道 | 21,499 | 0 | 0 | 21,499 |
| 幹線 | 1,832 | 577,212 | 15,307 | 594,352 |
| 生活（市町村道） | 544 | 39,139 | 462,919 | 502,603 |

## 5. 方式

### 5.1 式

区分 cat ∈ {自専道, 幹線, 生活} について、次のように計算する。

```text
C_cat = 区分 cat の事故件数（学習期間、自動車が関与する事故）
L_cat = 区分 cat の中心線の延長
d_cat = C_cat / L_cat                     … 延長あたりの事故件数
r_cat = 国交省の死傷事故率（H27：自専道9、幹線62、生活142）[2]
T_cat = d_cat / r_cat                     … 区分の平均交通量（逆算。相対値でよい）
f_cat = T_幹線 / T_cat                    … 区分の係数（幹線=1に正規化）

辺e（自動車）：            risk_e = f_cat(e) · S · Y_e      （今の c_k を f_cat に置き換える）
交差点クラスタv（自動車）： risk_v = f_cat(v) · S_v · Y_v    （今は係数なし。5.3節）
```

### 5.2 C と L の取り方：3つの案

| 案 | C（事故件数） | L（延長） | f 生活 | f 自専道 | 位置づけ |
|---|---|---|---:|---:|---|
| **A（主案）** | 警察の路線コードの区分別（帰属不明を含む） | 国交省の延長（幹線・生活はH21 [1]、自専道はH30 [2]） | **15.0** | **0.27** | 公的な統計だけで決まる。地図への割り当てとOSMの延長の誤差を含まない |
| B（感度） | 国交省のH20の延長あたり件数 [1] | 同左 | 13.5 | （出せない。Aの値を使う） | 国交省の資料だけで決まる。年が古い（H20） |
| C（感度） | OSMに割り当てた事故（写しを除く） | OSMの中心線の延長 | 18.8 | 0.44 | 経路探索で実際に使う区分と延長で計算する。service の延長を含む |

計算（2019〜2022年、自動車の事故1,206,496件。A・CはH27の事故率）：

```text
A：C = 自専道 22,682、幹線 601,679、生活 515,898
   d_幹線 / d_生活 = (601,679/181,204) / (515,898/1,015,861) = 3.321 / 0.508 = 6.54
   f_生活 = 6.54 × (142/62) = 15.0
   f_自専道 = (3.321/62) / ((22,682/12,675)/9) = 0.0536 / 0.199 = 0.27
B：f_生活 = (203/84) × (2.06/0.37) = 13.5
C：d_幹線 / d_生活 = (618,062/181,241) / (484,621/1,165,919) = 3.410 / 0.416 = 8.20
   f_生活 = 8.20 × 2.29 = 18.8、f_自専道 = (3.410/62) / ((23,907/21,380)/9) = 0.44
```

- 主案をAにする理由は、係数が「交通量の補正」なのか「地図の誤差の埋め合わせ」なのかを切り分けられることにある。Aの係数には、手元の地図への割り当ても、OSMの延長も入らない。
- CがAより大きいのは、主に service の延長（12.5万km、事故が少ない）が生活側の延長に入ること（延長の比 6.43対5.61）と、市町村道の事故の7.8%がOSMの幹線に割り当てられること（事故の比 1.275対1.166）による。
- 第1版の21.5は、写しを含む事故件数と上下線を別に数えた延長から計算していた。この数え方では、事故の多い分離帯のある幹線が二重に重く数えられる。

### 5.3 交差点クラスタ

主案では、交差点クラスタに、最上位の道路の区分の係数を掛ける（j/8 ＝ `top_group`）。

- 交差点の曝露量は、通常、交差点に入る交通量の合計で測る [7][9]。幹線と生活道路の交差点では、この合計は幹線の交通量でほぼ決まる。最上位の道路の区分の係数を掛けるのは、これを区分の平均で近似したものである。
- この近似では、交差点をどの向きに通るか（幹線を直進するか、生活道路から幹線に出るか）による危険の差は表せない。
- 交差点の補正の仕方で経路が大きく変わりうる（生活側の事故の54%が交差点にある）。そのため、9章で「交差点には掛けない」場合と比べる。

計画書4.4節のとおり、交差点のリスクはクラスタに外から入る有向辺に載る。そのため、「入ってくる辺の区分の係数を掛ける」という向きのある補正も実装はできる。ただし国交省の資料には根拠となる数字がないので、本計画には入れない。

### 5.4 区分とgroupの対応（係数を掛ける範囲）

| 区分 | 係数を掛けるgroup | 備考 |
|---|---|---|
| 自専道 | 0 | 国道の自動車専用道路のうちOSMで trunk として描かれている区間は、幹線側に入る |
| 幹線 | 1〜3 | |
| 生活 | 4〜10 | group 9（road）・10（track）も、国交省の生活道路（その他（農道・私道等）を含む）に合わせて生活側に入れる |
| （対象外） | 11〜15 | 自動車が通れない |

### 5.5 徒歩・自転車

変えない（係数1）。国交省の事故率は自動車の走行台キロあたりで、歩行者・自転車の通行量は資料にない。計画書5.6節の既知の弱点はそのまま残る。

### 5.6 評価の指標

| 指標 | 用途 |
|---|---|
| 今のY1〜Y3（事故件数） | 主の指標。定義は変えない |
| 曝露を補正した参考値 Y1x〜Y3x | 補正の仮定のもとでの整合を見る。**独立した検証ではない**（経路の選定と同じ係数を評価にも使うため） |
| 道路種別の構成・生活道路の割合・追加時間 | どういう経路になったかを見る |

- Y1x〜Y3x は、経路上の将来事故を1件ずつ数えるとき、その事故が載る経路の辺（交差点）の区分の係数を重みとして掛けたもの。Y3は割り当て先、Y2はマップマッチングで対応した辺、Y1は事故に最も近い経路の辺の区分を使う。
- 補正したリスクが現実の1台あたりの危険を表すかを、独立に確かめるデータはない。生活道路の交通量の観測がないためである。これは限界として報告に書く（7章）。
- 採用基準は設けない。件数版と補正版の両方をそのまま報告する。

## 6. なぜこの方式にするか：検討した案

| 案 | 内容 | 判断 |
|---|---|---|
| 今の c | group 5〜8 の辺に係数 c | 採らない。値の根拠がない。tertiary（市町村道）が対象外。交差点に掛からない |
| 国交省の事故率だけでリスクを作る | 区分の定数 × 延長 | 採らない。区間ごとの差（3.5節の集中）を捨て、手元の事故データを使わなくなる |
| **区分の平均の事故率を再現する係数（本計画）** | 5.1節 | **採る。** 一次資料の指標（死傷事故率）を区分の平均で再現し、区分の中の差は手元のデータ（経験ベイズ）で残す |
| 係数を割り当てた事故とOSMの延長から計算する | 5.2節のC | 主案にしない。割り当ての誤差とOSMの延長の違いが係数に入り、交通量の補正と区別できない。感度として残す |
| 国土数値情報の道路データ（N13）で区分を付け直す | N13の道路分類・幅員区分をOSMの辺に空間結合する | 今は採らない。区分の対応は、警察の路線コードとの照合（4.3節）と延長の一致（4.2節）で確かめられた。N13は位置の標準偏差が約25mで、都市部では対応付けが曖昧になる（計画書4.5節） |
| センサスで区間ごとに正規化する | 計画書5.7節 | 将来の拡張。国県道にしか観測がなく、対応付けに大きな作業が要る。市町村道の交通量は依然として分からない |
| ETC2.0 の急ブレーキなどを使う | 3.6節 | 範囲外。手元のデータが10地区分しかない。国交省も箇所選定にしか使っていない |

**事故率の年をH27にする理由**：3区分すべての事故率が載った資料の中で最も新しく、同じ資料に区分の定義と走行台キロの出し方が書かれている [2]。H20の値（[1]）は感度の確認（B案）に使う。

**幹線を1に正規化する理由**：経路の選定は比だけで決まるので、正規化しても選定は変わらない。延長あたりの事故が最も多い幹線を1にすると、表示する `weighted_risk` の大きさが今と大きく変わらない。

**係数を学習期間ごとに計算し直す理由**：C_cat は学習データの事故件数で決まる。本番のモデル（2019〜2025年で学習し直す）でも、その期間の事故で計算し直す。

## 7. 前提と限界

1. **区分の中の交通量の差は扱わない。** 4車線と2車線の primary、通過交通の多い市道と行き止まりの路地は、同じ係数になる。事故件数は交通量に比例せず、交通量のべき乗（指数は1より小さいことが多い）で増えるので [7]、区分の平均で割る方法は一次近似である。
2. **国交省の事故率は全国・全車種・全事故の平均である。** 手元は自動車が関与する事故で、評価は関東の4地域だけである。
3. **年がずれる。** 事故率はH27（2015年）、延長はH21・H30、事故件数は2019〜2022年（本番は2019〜2025年）。区分ごとの事故の減り方の差は補正しない。
4. **生活道路の事故率は推計の残差に基づく**（3.2節）。区分の中で最も不確かである。
5. **係数の推定の幅**：主案15.0に対して、国交省の資料だけの13.5、OSMの区分と延長による18.8がある。9章でこの幅の中での経路の違いを示す。
6. **交差点の補正は近似である**（5.3節）。通る向きによる危険の差は表せない。
7. **補正版の評価指標は独立した検証ではない**（5.6節）。
8. 徒歩・自転車には適用しない（5.5節）。

## 8. 実装

### 8.1 データ形式：`risk.bin` の `PARAMS`

任意の項目 `car_exposure` を足す（形式書14.4節）。

```json
"car_exposure": {
  "method": "route-code",
  "rates_source": "国土交通省 R2.9 資料4 スライド2（H27 死傷事故率）",
  "lengths_source": "本田（2011）スライド3（H21）、国土交通省 R2.9 資料4 スライド1（自専道 H30）",
  "reference": "arterial",
  "clusters": "top_group",
  "categories": [
    {"name": "motorway", "groups": [0], "route_classes": [5, 6, 7], "rate": 9,
     "length_km": 12675, "count": 22682, "factor": 0.27},
    {"name": "arterial", "groups": [1, 2, 3], "route_classes": [0, 1, 2, 3], "rate": 62,
     "length_km": 181204, "count": 601679, "factor": 1.0},
    {"name": "local", "groups": [4, 5, 6, 7, 8, 9, 10], "route_classes": [4], "rate": 142,
     "length_km": 1015861, "count": 515898, "factor": 15.0}
  ]
}
```

- `method` は `route-code`（A案）、`osm`（C案）、`factors`（係数を直接与える。B案と感度の確認用）のいずれか。`clusters` は `top_group`（主案）か `none`（交差点に掛けない）。
- **`car_exposure` がないときは、今の `c`・`c_groups` の動きのままにする。** 既存の release と既存のテストの期待値は変わらない。`car_exposure` があるときに `c` が1でなければ、risk-fit をエラーにする（二重に掛けないため）。
- 既定の動き（`car_exposure` なし）では、`PARAMS` のJSONに項目を書かない。今と同じ入力からは、バイト単位で同じ `risk.bin` ができる（タスクEと同じやり方）。

### 8.2 `routing_prep risk-fit`

- `--exposure-rates motorway=9,arterial=62,local=142`：事故率。
- `--exposure-method route-code|osm`、`--exposure-lengths motorway=12675,arterial=181204,local=1015861`（`route-code` のとき必須）。
  - `route-code`：学習期間の自動車の事故を、`accident_attrs.bin` の `route_class` で区分に分けて数える（帰属不明を含む。`route_class` 8〜14 と欠損は数えない）。`accident_attrs.bin` は今も risk-fit の入力である。
  - `osm`：割り当ての重み（写しを除く）を区分別に数え、延長は双子の辺を半分にした中心線の延長を使う。
- `--exposure-factors motorway=0.27,arterial=1,local=13.5`：係数を直接与える。
- `--exposure-clusters top_group|none`。
- 監査JSONに次を書く。
  - 区分ごとの件数・延長・d・r・T・f
  - 3つの方法（`route-code`・`osm`・国交省H20の13.5）の係数の並び
  - 路線コードとOSMの区分の照合表（4.3節の表）
- `--inherit-from` のときも、係数はその推定の学習期間の事故で計算し直す（W・β は今までどおり引き継ぐ）。

### 8.3 エンジン（`backend/src/domain/routing/risk/mod.rs`）

- `c_factor(k)` を「区分の係数」に一般化する。自動車で `car_exposure` があれば `f[k/8]`、なければ今の c の規則。
- 交差点クラスタのリスクに、自動車で `car_exposure` があり `clusters=top_group` なら `f[j/8]` を掛ける。
- `RiskVariant::ExpectedCount`（較正用の期待件数）には掛けない。今の c と同じ扱い。
- 表示する `weighted_risk` にも係数を含める（計画書5.5節の既存の決定）。高リスク区間のしきい値は件数で判定するので影響しない。
- API の型（openapi）、フロントエンド、③の範囲は変えない。

### 8.4 評価（`routing_eval y-metrics`）

- `--exposure <risk.bin>` を足し、その `car_exposure` の係数で Y1x〜Y3x を出す（5.6節）。指定がなければ今の出力のまま。
- 自動車以外の手段では、係数1として補正版も件数版と同じ値を出す。
- `data/work/M5/scripts/analyze.py` に、補正版の低減率・勝率・区間を足す。

### 8.5 テスト

- 係数の計算：区分が2つの合成データで、`route-code`・`osm` の両方で d・T・f が手計算と一致する。`osm` で写しを数えず、双子の延長を半分にすることも確かめる。
- **エンジンを通した集計**：合成のグラフで、エンジンが返す辺と交差点のリスクを区分ごとに足し、延長と区分の平均交通量で割ったときに、事故率の比が与えた比と一致する。係数の計算の式だけでなく、`S · Y_e` と経験ベイズを通した値で確かめる。事前分布の項があるので完全には一致しない。許容差は、事故の多い合成データで決める。
- エンジン：`car_exposure` があると、辺と（`top_group` のとき）交差点クラスタに係数が掛かる。徒歩・自転車と `ExpectedCount` には掛からない。`clusters=none` で交差点に掛からない。
- 既定の動き：`car_exposure` がないとき、今のテストの期待値と `risk.bin` のバイト列が変わらない。
- 辺の分割の不変性（形式書14.5節）が、係数を掛けても成り立つ。
- `tests/routing_real_release.rs`（`#[ignore]`）を、release を作り直すたびに流す。

### 8.6 文書の更新

- 計画書：5.5節を本方式で書き換える（c の掃引は M5.md の付録に移す）。5.7節に本方式との関係を書く。9.3節に補正版の指標を足す。12.1節に決定を追記する。
- 形式書：14.4節に `car_exposure` を足す。14.5節の式に f_cat を入れる。18章に y-metrics の補正版を足す。
- 本書を `docs/routing-reports/M5.md` から参照する。
