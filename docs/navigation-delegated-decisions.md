# GPSナビ機能の委任判断

2026-10-24、GPT-6 Astraによる技術判断。GPT-6.1 Solへ委任したが、Solの混雑で中断した作業を再開した際にCodex側でGPT-6 Astraへ自動で切り替わり、本書の判断はAstraが行った。利用者はこの経緯を確認したうえで、内容をそのまま採用すると決定した（2026-10-24）。**利用者決定は機能の範囲と利用方針、委任判断は本書の形式・計算方法・暫定値**を指す。仕様書への反映記録であり、実装・実機検証・配備の完了を示すものではない。

根拠は [spec-decisions.md](spec-decisions.md) の「確定：GPSナビ機能の追加（利用者決定、2026-10-24）」と他の確定事項。`app/`・`backend/`・`frontend/` は根拠にせず変更しない。ネットワーク照会は行わず、既存文書の外部仕様と一般知識を使った。外部条件の現行性、法令の適用と端末固有の挙動は**要確認**として残す。

## 利用者確認済みの前提

- A（経路上の現在地・残り距離/時間・逸脱表示）＋B（危険区間への画面/音声通知）＋模擬走行を採用。開始対象はfastest_idとnullでないsafest_idだけ。
- 照合はブラウザ内。定期的な位置送信、位置履歴保存、バックグラウンド追跡を行わない。
- 逸脱時は表示と明示的な再検索ボタン。steps・曲がり角案内・自動再検索・軌跡ファイル再生は対象外。
- 模擬走行は所要時間に合わせた自動移動、倍速・一時停止・揺らぎを持ち、実機GPSと同じ処理を使う。
- 表示用high_risk_sectionsの上位100件、非緩和、72m・σ=24m、天候倍率、外部提供元ログ許容、Cloud Run＋IAP、既存上流制限を維持する。

## GPT-6 Astraによる委任判断：進捗・通知・再検索

| 項目 | 決定と根拠 |
|---|---|
| GPS | 明示開始でwatchPosition（enableHighAccuracy=true、timeout=10000、maximumAge=1000）。精度30m以下、取得後5秒以内の新しい位置だけを判定に使う。停止・非表示・権限拒否・再検索等でclearWatch。30mは75m小線分や逸脱距離に対して誤通知を抑える初期値で、実測前。 |
| 射影 | 局所平面で選定geometryへ射影し、前回距離と時間に応じて候補を制限。歩3/自転車12/車40m/sを飛び検出の保護値とし、後戻りは許す。30m超離れた距離軸の候補が横距離10m以内の差で競合したら保留。道路網へのマップマッチングは採用しない。詳細はfrontend-spec 7.3。 |
| 進捗と到着 | p/LでOSRM distance/durationを按分する概算。到着はpがLの90%以上かつ残り局所距離20m以下、実測位置が経路終点30m以内の状態を5秒・3測位以上。飛びと短経路での即時到着を抑える。 |
| 接近距離 | walk=80m、bike=150m、car=300m。代表速度約1.4/4.2/13.9m/sで約57/36/22秒前を狙う暫定値。保証された猶予や停止距離ではない。精度良好・一意照合・前進時だけ通知。 |
| 通知抑止 | 結合済み区間ごとにナビセッション中最大1回。1秒以上隔てた2測位で接近を確認、接近解除は閾値+30m、通過はend_m+30m。重なる通知は1発話にまとめ、音声開始間隔10秒以上、期限切れを後追いしない。連続区間を結合することで音声の連発を抑える。 |
| 音声 | 日本語の短い定型文で過去事故の参考情報と伝える。開始操作でja-JP音声を試し、端末内音声を優先。未対応/日本語音声なし/発話失敗は画面通知へ。音声に座標・住所を含めず、外部TTSを追加しない。iOSの操作起点や音声可用性は実機で要確認。 |
| 逸脱/復帰 | 精度良好時だけ、横距離>max(40m,2×accuracy)が10秒・3測位以上で逸脱。復帰は一意照合かつ横距離<=max(20m,accuracy)が5秒・3測位以上。測位間隔5秒超で連続判定をリセット。別閾値と継続時間で揺れによる反転を抑える。 |
| 明示的再検索 | 現在地を新origin、目的地・mode・max_detour_minを保持、出発日時は現在。地点変更なので15分未満でもconditionsを取り直す。nowの手動条件は維持、custom→nowでは既存日時変更規則に従い自動へ戻す。成功時は同じ選定種別で継続、safest=nullなら停止して選択を求める。 |
| 競合/失敗 | ナビ・位置取得・条件・routeの世代を束ね、旧応答/音声/タイマーを破棄。二重検索を抑止、503・非JSON・IAP失敗を自動再送しない。検索開始で旧結果を解除し、失敗後は停止状態で手動再試行。 |

## GPT-6 Astraによる委任判断：模擬・ブラウザ・安全

| 項目 | 決定と根拠 |
|---|---|
| 模擬速度と時計 | 基準速度distance/duration、距離軸はL/durationで進む。1/2/4/8倍、仮想1秒ごとに位置を生成。判定器にも同じ仮想時計を渡し、倍速で飛び/逸脱/到着の試験結果が変わらないようにする。音声開始間隔だけ実時間10秒とする。 |
| 揺らぎ | uint32 seed（既定1）、LCG `x=(1664525*x+1013904223) mod 2^32`、u=x/2^32。2乱数から半径8sqrt(u1)m・角2πu2の円内一様ノイズ。accuracy=10m、揺らぎOFFも可。GPS座標/accuracyと同じ入力型を通す。 |
| 実演/逸脱試験 | IAP配下の本番実演でも明示選択で使える。常時「模擬走行中」、倍率・一時停止を表示し実GPSと排他。試験用操作で進行方向の左へ120m・仮想20秒のずれを加える。手動再検索はその合成位置から通常APIを呼ぶため外部通信があることを操作前に示す。 |
| 非表示/電池 | Screen Wake Lockは任意の補助。拒否しても利用可。hidden/pagehideではwatch・模擬時計・音声・Wake Lockを停止、visibleでも自動再開せず明示再開。OSによる停止/権限撤回は保証できない。 |
| IAP/オフライン/SW | セッション確認の定期通信なし。メモリ内ナビは通信不要、取得済み経路でオフライン継続可。再検索不可、再訪はシェルだけ。地図不可なら新規開始不可・進行中は停止。認証失敗は停止し停車後の再ログイン案内。ナビ中のSW強制切替・再読込なし。 |
| 操作と安全 | 開始前に注意を確認。自動車・自転車走行中の注視/保持操作を求めず、検索条件や複雑な操作はナビ中抑止。再検索・復帰・認証・設定は安全な場所で停止して行う。速度から法的な停車を自動判定しない。 |
| 法令 | 道路交通法のながらスマホ規制、2024年11月からの自転車の罰則を踏まえた設計。条文の適用範囲・最新改正・注意文の最終適否は法的判断として要確認。罰則額を未確認で断定しない。 |
| プライバシー | 実GPS・模擬位置・進捗・通知済み集合はメモリだけ。限定した直近値と判定タイマーを使い、軌跡配列を蓄積しない。ログ/ストレージ/URLへ保存しない。送信は明示検索と既存conditions規則だけ。外部タイルに表示範囲が伝わる既存条件は区別して説明する。 |

## 統合時の変更と残件

計算・サイズ・fixtureは [api/behavior.md](api/behavior.md) 7・11章、型と応答例は [api/openapi.yaml](api/openapi.yaml)、操作・判定・実機受け入れは [frontend-spec.md](frontend-spec.md) 7・11章へ反映する。数値や意味を変更するときはこれらと本書を同じ変更単位で更新する。

**要確認**：実端末でのGPS精度/電池/音声/Screen Wake Lock、交差・並行道路での保留頻度、暫定閾値の妥当性、最大応答のRAM/時間、IAPセッションとPWA更新、経路/タイル提供元が実演時の利用を許す条件、法令・注意文の最終確認。機能範囲の決め直しではなく、実装・配備前の検証残件とする。

## GPT-6.1 Solによるレビュー指摘の修正（2026-10-24）

利用者の技術判断委任に基づき、レビューの5件を修正する。以下は上記のGPT-6 Astraによる判断を一部置き換え/補足する現行規則であり、利用者決定と既存の事故集計・上流制限は変更しない。ネットワーク照会・実装・配備の検証は行っていない。
