## 6. 推測で決めた点・計画から外れた点

1. ★**天候の項を線形の形に変えた**（形式書14.5節を更新）。M0の形 `ŷ·(1 + (M_w−1)·ρ_e)`、`ρ_e = (n^w + β·ρ_k)/(n + β)` は、比を取るので、辺を分けると合計が変わり、雨・霧・雪の天候で分割の不変性（behavior.md）が成り立たない。代わりに `Y = ŷ + (M_w−1)·ŷ^w`、`ŷ^w = (1−W_w)·μ·ρ_k + W_w·n^w`、`W_w = T·R·ρ_k/(T·R·ρ_k + β)` とした。βは1mあたりの母数になる。交差点用に `beta_cluster` を `PARAMS` に足した（ないJSONでは `beta` と同じ値）。M0の契約（形式書）の変更だが、behavior.md の不変性を守るための変更で、APIの型と挙動の約束は変わらない。
2. **urbanの代替**：人口集中地区の境界データの代わりに、事故原本の地形コードから推定した（形式書14.2節、計画書から外れる）。M5の報告にも書く。
3. **bandの双子**：P6は辺ごとに「自分の `lanes` に、双子のうち `lanes` が分かる辺の最大値を足す。分からなければ自分の2倍」とした（形式書14.2節）。
4. **Wの親**：学習件数100未満の種別は、poolingと同じ階層順で件数100以上になる最初の親の辺をまとめてWを推定し、`a` は自分のRで換算した。s・ρの親は30件のしきい値で別に選ぶ。
5. **βの逸脱度**：ρ_k=0の種別（学習年にその天候の事故がない）の項は、予測がβによらず0なので、比較から外した（指示役が修正。外さないと全候補が不採用になり、βが最小の候補に落ちる）。
6. **ALTの下界**：表の下界が0のとき（ランドマークから届かない島など）だけ、直線距離の下界で補う。既存のテスト（`routing_search.rs`）が表の下界の値を固定しているため、常に最大を取る形にはしていない。呼び出し側はもともと直線距離との最大を取る。
7. **`find_routes` は `check_path` を呼ばない**：`SearchContext` が `Restrictions` を持たないため。合法性は、探索が照合器で守り、結合試験と `route-batch` で `check_path` を使って確かめている（違反0）。
8. **`ellipse_nodes`** は出発・到着の仮想ノードを含む数（上限の判定は実ノード数）。
9. **`route-batch` の記録**：探索の状態は `status` と名前が衝突するので `search_status` にした。`total_ms` は候補の整理までで、検証の時間は含めない（指示役が修正）。
10. **`risk-fit` のJSONの浮動小数**：`serde_json` の往復で `PARAMS` が1ulp違う値になる問題に、作業役は「往復で変わらない近い値に補正する」処理を入れた。値の差は相対1e-15程度で、推定には影響しない。きれいな解決ではないが、M3bでは残した。

## 7. 観察と未解決の問題

1. ★**bestが遠回りの上限をほぼ使い切る**：bestがp0と違う割合は93〜100%で、追加時間の中央値は上限600秒に対して485〜594秒、リスクの削減率の中央値は0.61〜0.73。「上限内でリスクが最小」という定義どおりだが、リスクの差が小さくても上限まで遠回りする。M5の評価で、削減の大きさと追加時間の関係（例：削減率あたりの追加時間）を確かめ、候補の整理（behavior.md）で十分かを判断する。
2. **carのすそ野**：東京23区のcarで99%点が10.7秒（関東4地域の99%点は8.5秒）。主な原因はLARACとペナルティ法。楕円の上限を下げるか、LARACの反復を減らすか、別経路の探索に予算を設けるかを、M5で計測して決める。
3. **本番用の `risk.bin`**：計測には学習2019〜2022年の推定を使った。本番（学習2019〜2025年）では検証年を取れないので、Wを2019〜2022年の推定から引き継ぎ、新しいRで `a` を換算する手順が必要になる（`risk-fit` にWを外から与える引数がまだない）。M4・M5でreleaseを作るときに足す。
4. **メモリ**：route-batchのVmHWMが3.1GBで、M4.2の上限3.2GBに近い。`alt.bin` の読込時に一時的に2倍になる（ファイルを読んでからデコードする）ので、M4ではmmapか逐次のデコードを検討する。
5. **大きな障害物の領域**（M1からの持ち越し）：今回の1,800組では発生しなかった。
